## Origen y alcance

ICA utiliza Flutter. Para realizar el taller en Ionic se importa sin cambios el
[starter del curso](https://github.com/code-corhuila/programacion-movil-2026-b-starter-react).
La adaptación conserva el dominio de ICA: sabores, categorías, precios en COP,
tamaños, toppings y flujo de añadir al carrito. No es una migración completa del proyecto.
El código de referencia de ICA corresponde al commit `6d7882db6555ed9aea749709ee4784be895dd72f`.
La documentación consultada corresponde al commit `7c26be0968cebb30e16cc86533d569d219942009`.

## Ejecutar

Desde `11-week/workshop/app`: `npm ci` y `npm run dev`.
Verificación: `npm run build` y `npm test`.
El starter abre en navegador y compila antes de modificarlo.
