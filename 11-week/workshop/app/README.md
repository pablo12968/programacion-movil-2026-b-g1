# ICA - prototipo Ionic de la semana 11

Ejecutar: npm ci y npm run dev.
Validar: npm test, npm run build y npm run lint.

Datos demo tomados de ica.app. Sin VITE_ICA_API_URL no envia pedidos reales ni cobra.
Con esa variable se conecta al catalogo y pedidos de ICA. Carrito e historial se conservan durante la sesion. Los archivos originales del starter
se conservan en el commit de linea base c5644f1.

Consulta ../README.md y ../docs/ para el alcance y las evidencias del taller.
